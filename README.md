# Aplikasi Belajar Flutter

## Deskripsi
Aplikasi ini dibuat sebagai tugas mata pelajaran Rekayasa Perangkat Lunak (RPL) di SMK Brantas Karangkates. Proyek ini menggunakan framework Flutter dan bahasa pemrograman Dart untuk mempelajari dasar-dasar pengembangan aplikasi lintas platform. Aplikasi dijalankan pada Windows Desktop menggunakan Visual Studio Code dan Visual Studio Community.

## Fitur
- Menampilkan halaman utama Flutter (Counter App).
- Menggunakan widget bawaan Flutter.
- Menampilkan contoh penggunaan variabel dan tipe data.
- Menampilkan hasil perhitungan sederhana.
- Dapat dijalankan pada Windows Desktop.
- Mendukung pengembangan menggunakan Git.

## Teknologi
- Flutter
- Dart
- Visual Studio Code
- Visual Studio Community
- Git

## Cara Menjalankan
1. Clone atau unduh repositori ini.
2. Buka folder proyek menggunakan Visual Studio Code.
3. Jalankan perintah berikut pada terminal:

```bash
flutter pub get
flutter run -d windows
```
